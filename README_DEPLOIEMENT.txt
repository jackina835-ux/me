PORTFOLIO — VERSION TRÈS PROFESSIONNELLE

1. Décompressez le dossier.
2. Envoyez TOUT le contenu dans votre dépôt GitHub Pages.
3. index.html doit rester à la racine.
4. Conservez le dossier assets et toutes les pages HTML.
5. GitHub Pages : Settings > Pages > principal/main > /(racine).

Le portfolio inclut un mode clair/sombre, une page principale avec un seul aperçu par projet et des pages détaillées pour chaque projet.
